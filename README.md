# es-student
Задания курса "Встраиваемые системы" от команды ant-lab

В списке прогонов появился 3.2.1 Индикатор записи с зелёной галочкой. У прибора появилась первая функция, которую выполняет обработчик прерывания, а не суперцикл.
В списке прогонов появился 3.2.2 Захват по таймеру с зелёной галочкой. У вас есть измерения, которые обосновывают выбор делителя АЦП в ТЗ на рекордер.
В списке прогонов появился 3.2.3 Захват блока через DMA с зелёной галочкой. Шаг отсчётов держит АЦП, а переносит их DMA. Ядро узнаёт только о готовом блоке.
В списке прогонов появился 3.2.4 Поток с двойной буферизацией с зелёной галочкой. Рекордер передаёт 44 100 отсчётов в секунду без единой потери, а длину записи теперь ограничивает только компьютер.
